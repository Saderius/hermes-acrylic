Linux / no-Glass acrylic fallback

Same recipe as the plugin when [data-hermes-glass] is absent: blur the stand-in wallpaper with blur(30px) saturate(1.25), then paint the reference --material-tint at alpha .55. Composer, bubble, menu, and code stay solid. This does not blur other apps. Real acrylic is still Win11 Glass, frost under-window, scope window.
